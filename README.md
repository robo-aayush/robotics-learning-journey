## 🚧 Current Build : Smart Dustbin
An Arduino-based dustbin that open its lid automatically when someone comes near.

**Components:**
- Arduino Uno
- Ultrasonic sensor (HC-SR04)
- Servo motor (MG90S)
- Jumper wires and breadboard
- 9V battery or USB power

**How it works:** The ultrasonic sensor measures distance. When something comes within about 20cm, the servo opens the lid. After a few seconds, the lid closes again.
