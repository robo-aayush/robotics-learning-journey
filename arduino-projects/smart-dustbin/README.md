# 🗑️ Smart Dustbin

An Arduino-based dustbin that opens its lid automatically when someone comes near.

## Components
- Arduino Uno
- Ultrasonic sensor (HC-SR04)
- Servo motor (SG90)
- Jumper wires and breadboard
- 9V battery or USB power

## How It Works
1. The ultrasonic sensor keeps measuring distance.
2. When something comes within about 20 cm, the servo turns and opens the lid.
3. After a few seconds, the lid closes again.
